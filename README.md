# Sitio Web & Portfolio Profesional - Arnaldo Guerrero

> 🌐 **Sitio Web en Vivo:** [https://arnaldo-guerrero.web.app](https://arnaldo-guerrero.web.app)

Sitio web personal y portfolio interactivo de **Arnaldo Guerrero**, Ingeniero Electromecánico & GenAI Engineer. El proyecto destaca la convergencia entre más de 15 años de experiencia en automatización industrial, plantas de proceso y el desarrollo moderno de software con Inteligencia Artificial Generativa y agentes autónomos.

---

## 🎯 Propósito del Sitio

El objetivo principal es presentar de forma visual, profesional e interactiva el perfil técnico de Arnaldo Guerrero, demostrando cómo los principios rigurosos de la ingeniería física y de control industrial se aplican a la arquitectura de software, backend con Python/FastAPI y la orquestación de LLMs mediante grafos de agentes (LangGraph).

---

## ✨ Secciones Principales

- **Hero & Perfil:** Presentación inicial, propuesta de valor y accesos rápidos a contacto y redes.
- **Sobre Mí (Background):** Explicación de la evolución profesional desde el diseño con PLCs, variadores e instrumentación de planta hasta la ingeniería de agentes de IA y software.
- **Proyecto Destacado (Caso de Estudio):** Muestra detallada del *Presupuestador de Tableros Eléctricos con IA*, incluyendo arquitectura técnica, flujo de 3 agentes (LangGraph), generación de esquemas CAD 2D interactivos y presupuestos en USD estilo ERP.
- **Proyectos & Repositorios de GitHub:** Colección de proyectos de código abierto y herramientas desarrolladas.
- **Trayectoria & Experiencia:** Recorrido cronológico con más de 15 años en plantas industriales, puestas en marcha y mantenimiento especializado.
- **Matriz de Habilidades & Educación:** Clasificación de competencias en GenAI & Agentes, Automatización Industrial y Desarrollo Fullstack.

---

## 🚀 Características Técnicas y Funcionalidades

- **🌐 Soporte Multilenguaje:** Conmutador instantáneo entre Español (ES) e Inglés (EN) con persistencia de selección.
- **🌓 Modo Oscuro / Claro:** Tema dinámico adaptable con guardado de preferencias en `localStorage`.
- **📱 Diseño Totalmente Responsivo:** Adaptado para dispositivos móviles, tablets y escritorios con animaciones fluidas y tokens de diseño modernos.
- **🔍 Modal Interactivo de Caso de Estudio:** Vista en profundidad con diagramas de flujo y desglose de arquitectura.

---

## 🛠️ Stack Tecnológico

- **Framework:** [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Estilos & UI:** [Tailwind CSS](https://tailwindcss.com/) con sistema de tokens de diseño personalizado
- **Iconografía & Tipografía:** [Lucide React](https://lucide.dev/), Google Fonts (*Hanken Grotesk*, *Inter*, *JetBrains Mono*)
- **Estructura de Datos:** Módulos centralizados de internacionalización (`translations.js`)

---

## 💻 Instalación y Ejecución Local

Para levantar el proyecto en tu entorno local:

1. **Instalar dependencias:**
   ```bash
   npm install
   ```

2. **Iniciar servidor de desarrollo:**
   ```bash
   npm run dev
   ```

3. **Construir para producción:**
   ```bash
   npm run build
   ```

4. **Previsualizar la compilación de producción:**
   ```bash
   npm run preview
   ```
